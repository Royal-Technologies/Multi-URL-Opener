# Multi URL Opener

A simple and lightweight browser-based tool for opening multiple URLs with a single click.

Built by **Royal Technologies**, Multi URL Opener makes it easy to open a list of web addresses at once instead of opening each URL manually.

## Live Demo

**Try Multi URL Opener:**

https://royal-technologies.github.io/Multi-URL-Opener/

## About

**Multi URL Opener** is a free browser-based utility for opening multiple URLs simultaneously.

Simply enter your URLs in the text area. URLs can be entered:

* One URL per line
* Separated by commas
* Separated by spaces

Then click **Open All** to open the URLs in your browser.

The tool also supports keyboard shortcuts for faster operation.

## Features

* Open multiple URLs with one click
* Enter URLs line by line

## Keyboard Shortcuts

| Shortcut       | Action              |
| -------------- | ------------------- |
| `Ctrl + Enter` | Open all URLs       |
| `Ctrl + R`     | Reset the URL input |

## How to Use

1. Open **Multi URL Opener**.
2. Enter the URLs you want to open.
3. Use one URL per line, commas, or spaces to separate them.
4. Click **Open All**.
5. All provided URLs will be opened by the browser.

### Example

```text
https://google.com
https://github.com
https://royaltechbd.com
```

You can also enter them in a single line:

```text
https://google.com, https://github.com, https://royaltechbd.com
```

## Privacy

Multi URL Opener is designed to work directly in the user's browser.

The tool does not require an account or database for its basic functionality.

Users should avoid entering sensitive or private URLs when using a public computer or shared browser.
